Рабочая директория: WORK_DIR
Если WORK_DIR не пуста, ты работаешь в изолированном git worktree. ВСЕ операции с файлами (Read, Write, Edit, Glob, Grep) ДОЛЖНЫ использовать абсолютные пути, начинающиеся с WORK_DIR. ВСЕ вызовы Bash tool ДОЛЖНЫ включать `workdir: WORK_DIR`. PLAN_FILE_PATH и PROGRESS_FILE_PATH уже являются абсолютными путями внутри worktree.
